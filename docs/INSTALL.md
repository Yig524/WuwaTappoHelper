# 安装与使用

[返回 README](../README.md) · [使用风险与免责声明](DISCLAIMER.md)

## 先确认你下载的是哪种包

| 文件 | 适合谁 | 下载后做什么 |
| --- | --- | --- |
| `WuwaTappoHelper-windows.zip` | 日常使用者，推荐 | 完整解压，配置官方桌宠位置，双击助手 EXE |
| `WuwaTappoHelper-source.zip`、GitHub 的 `Source code (zip)` 或克隆的源码 | 想审查、修改、自己编译的开发者 | 按 README 的构建命令生成 EXE；源码包没有现成启动 EXE |

本工具是便携程序，没有安装向导。**先完整解压，再从解压后的文件夹启动；不要在 ZIP 预览窗口中运行，也不要只拖出一个 EXE。** 仓库尚未发布 Release 时，只能先从源码构建。

需要 Windows 10/11、系统 Windows PowerShell 5.1 和 .NET Framework 4.8。无需安装 PowerShell 7、Python、Node.js 或 Visual Studio。官方 WuwaTappo 需另行安装并能正常登录；本项目不附带官方安装程序。

当前校验对象为官方 WuwaTappo **1.0.2**。即使文件版本相同，EXE 内容不一致也会被拒绝；程序更新后需要重新核对适配，不能通过改配置绕过校验。

## 第一步：完整解压

在本仓库的 GitHub **Releases（发布）** 页面下载 `WuwaTappoHelper-windows.zip`，使用资源管理器“全部解压”到固定、可写的位置，例如“文档”或自己的工具目录。

找到包含下列文件的那一层目录，这一层就是本文所说的**助手目录**：

```text
WuwaTappoHelper/
├── WuwaTappoHelper.exe          ← 日常双击这个文件
├── WuwaTappoHelper.exe.config
├── Run-UiaHelper.ps1
├── UiaHelper.ps1
├── UiaEngine.cs
├── SetupWizard.cs              ← 首次使用向导运行源码
├── Dashboard.cs
├── SmartLogic.ps1
├── helper-config.example.json
├── 开始使用.html               ← 双击可在浏览器查看离线说明
├── assets/
├── docs/
└── third-party/
```

配套 `.cs` 和 `.ps1` 文件属于运行所需内容，并非可以随意删除的开发文件。可以为 EXE 创建快捷方式，**不要把 EXE 移出这个文件夹**。

## 第二步：完成首次使用向导

从助手1.2.0起，首次打开会出现三步向导：

1. **选择官方桌宠**：点击“选择程序…”选中官方 `WuwaTappo.exe`，也可以直接填写路径。点击“校验并继续”，通过已核对的1.0.2哈希检查后才可继续；错误路径、助手EXE和不兼容文件不会被接受。
2. **检查连接**：手动启动官方桌宠并登录，向导只读等待窗口和余额就绪。连接成功后点“继续”；暂时不方便运行桌宠，可点“稍后连接，先看使用步骤”。
3. **准备开始**：阅读验证、任务和退出说明，点“保存并进入主界面”。程序将路径及向导版本保存到本机 `helper-config.json`，保留已有其他设置。

点击“取消”、按Esc或关闭向导不会覆盖原配置。向导不自动启动官方桌宠、不发送F24、不领取箱子、不启用自动开关。F24验证和选择任务仍由你进入主界面后主动操作。

正常保存后不会每次显示；配置损坏、路径失效或官方文件不兼容时会重新引导。主动重设可先退出助手，再在助手目录的PowerShell中执行：

```powershell
.\WuwaTappoHelper.exe --setup
```

### 高级：手动配置（可选）

通常使用向导即可。下面的目录关系与JSON配置仍然可用。

需要手动配置时，以下两种方式选一种即可。

### 方式 A：放在官方程序的子目录，不编辑配置

找到实际的官方 `WuwaTappo.exe`，把整个助手文件夹放到它旁边，形成下面的关系：

```text
官方桌宠安装目录/
├── WuwaTappo.exe                ← 官方桌宠
├── 其他官方文件……
└── WuwaTappoHelper/             ← 整个助手文件夹
    ├── WuwaTappoHelper.exe      ← 助手
    ├── assets/
    └── 其他助手文件……
```

助手默认查找其目录上一级的 `WuwaTappo.exe`。助手文件夹叫什么不影响查找，但不要再多套一层解压目录。如果已经存在 `helper-config.json`，其中设置的路径会优先使用。

### 方式 B：分开放置，编辑路径配置

如果不想改动官方安装目录，推荐使用此方式。

1. 在助手目录中**复制** `helper-config.example.json`。
2. 把副本重命名为 **`helper-config.json`**，原来的示例文件可保留。
3. 用记事本打开副本，把 `OfficialExecutable` 的值改为官方 EXE 的完整路径。例如：

```json
{
  "OfficialExecutable": "D:/Games/WuwaTappo/WuwaTappo.exe"
}
```

4. 将示例中的 `D:/Games/...` 换成自己电脑上的真实路径，保存后重新启动助手。

这里使用正斜杠 `/`，可以避免 JSON 的反斜杠转义问题。若使用反斜杠，必须写成 `D:\\Games\\WuwaTappo\\WuwaTappo.exe`。路径有空格也可以，仍保留两侧英文双引号。

在资源管理器中开启“查看 → 显示 → 文件扩展名”（Windows 10 为“查看 → 文件扩展名”），确认文件不是 `helper-config.json.txt`。路径应指向**官方桌宠 EXE**，不是助手 EXE、卸载程序或 `.lnk` 快捷方式。可在官方桌宠快捷方式的“属性 → 目标”中查看实际位置。

## 第三步：先连接，暂不开自动任务

1. 启动官方 WuwaTappo 并登录，确认桌宠已出现。
2. 双击助手目录中的 `WuwaTappoHelper.exe`。
3. 核对启动文件来源，正常处理 Windows 的 UAC 管理员确认。本助手当前统一请求管理员权限，以匹配已验证客户端的运行权限。
4. 等待“已连接官方桌宠”，核对余额和左右箱子状态。默认两个自动任务开关都关闭，启动本身不会自动发键或领取。

本程序未使用代码签名证书，Windows 可能显示未知发布者或信誉提示。只运行你确认来源的发布包；遇到安全软件拦截时先核对来源或选择自行构建，不建议关闭安全防护。

“可用余额”表示当前能用于领取的次数，不是距下一箱的剩余点击数。“补充次数”是助手本轮发送次数，不等于官方累计计数。余额不足时，某些槽位可能不显示，不一定是识别失败。

## 第四步：验证后再启用

### 需要自动补余额

1. 保持助手窗口在前台，点击“**验证 F24 · 5次**”。
2. 随后停止键鼠操作约 **12 秒**。程序先建立安静基线，再发送5次F24并观察官方余额变化；期间不要切窗口或移动鼠标。
3. 等待明确的“验证通过”。若中途有其他输入，先停止，重新做一次验证；不要反复快速点击验证按钮。
4. 通过后勾选“自动补充余额”。关闭重开助手或官方窗口身份改变后，需要重新验证。

### 需要自动领取

余额足够且箱子就绪后，可以点击“**验证领取 · 单箱**”验证一次。这不是只读测试：**会消耗约1,000余额，领取一个箱子**。它是可选的人工检查，不是自动领取的强制解锁条件。

确认状态后，按需勾选“自动领取箱子”。只启用领取时，不要求通过F24验证；余额可以来自你平时的自然输入。

### 开始运行

选择任务后点击“**开始运行**”。需要同时补充和领取时开启两个开关。程序优先处理就绪箱子，随后按余额反馈尝试补到2,000；不会加速官方30分钟冷却。只开启补充且存在可领箱子时，可能优先等待该箱领取，此时可手动领取或开启自动领取。

## 日常操作与暂停原因

| 操作 / 显示 | 含义 |
| --- | --- |
| `Ctrl+Alt+F8` 或主按钮 | 开始 / 暂停 |
| `Ctrl+Alt+F9` 或“停止” | 停止自动动作，继续只读观察 |
| 关闭或最小化窗口 | 隐藏至托盘，不是退出 |
| 双击托盘图标 | 恢复窗口 |
| 托盘右键“退出程序” | 真正退出助手 |
| 输入框 / 编辑区域保护 | 焦点仍在可编辑区域，即使暂时没打字也会避让；点击输入框外恢复 |
| 近期键盘输入 | 键盘停止约1秒后再尝试；不是所有鼠标操作后都等10秒 |
| 候选窗口 / 持续按键 / 拖拽 | 等待选词结束、松开按键或鼠标按钮 |
| 正在确认焦点 | 点击或切窗口后重新检查；鼠标移动、滚轮不重置等待 |

开启讯飞或其他中文输入法本身不应造成整段暂停，但自绘编辑器、输入法兼容性和软件自身的F24绑定仍可能影响体验。发现干扰时先按停止快捷键。

## 常见问题

| 现象 | 优先检查 |
| --- | --- |
| 下载后找不到助手 EXE | 是否下载了源码包 / GitHub的Source code？日常使用应下载windows发布包 |
| 提示文件缺失、启动失败 | 是否完整解压？是否只移动了EXE？查看助手目录下的`diagnostics/uia-host.log`和`uia-startup.log` |
| 找不到官方EXE | 检查第二步的目录关系或配置文件名、真实路径；修正后重启 |
| 官方程序更新 / 内容变化 | 当前仅接受已核对的1.0.2文件；等待适配，不要修改或跳过哈希校验 |
| 长时间等待连接 | 确认官方桌宠已运行并登录、UAC已允许，再点“刷新 / 保存诊断”；持续失败时查看日志 |
| 余额足够但不继续补充 | 达到储备目标会等待；就绪箱子也可能优先等待领取，检查自动领取开关 |
| 箱子冷却结束却未领取 | 检查余额是否足够、按钮是否真正就绪、自动领取是否开启、是否处于输入避让；完整冷却周期和异常恢复并非所有场景都已验证 |
| 一直输入避让 | 点击输入框外等待片刻；仍不恢复时查看`input-guard.json`中的原因，不要直接关闭输入保护 |
| 再次运行仍看到旧界面 | “×”仅隐藏窗口；先从托盘右键退出旧实例，再运行新版本 |

请勿同时运行多个类似助手，以免重复发键、领取和干扰验证。

## 升级、卸载和反馈

升级前停止任务并从托盘退出助手；完整解压新版到新文件夹，需要时复制自己的`helper-config.json`，核对路径后重新验证。不要只替换EXE或覆盖正在运行的文件。

卸载时从托盘退出，删除助手文件夹及自行创建的快捷方式即可。本项目不安装开机启动、服务或计划任务。卸载不能撤销已发生的计数和领取；官方桌宠安装、账号和云端数据仍由官方软件管理。

反馈时说明Windows版本、官方桌宠版本、助手版本、使用的输入法、复现步骤和界面状态。通过“刷新 / 保存诊断”保存本机信息，分享前检查并遮盖路径、余额、窗口标识或截图中的个人信息，**不要上传整个官方安装目录或账号数据**。
