1 · 完整解压 Windows 发布包

日常使用下载 WuwaTappoHelper-windows.zip，不是 GitHub 的 Source code。先“全部解压”，找到 WuwaTappoHelper.exe。保留所有脚本、源码、配置和assets文件夹，不能只移动EXE，也不要在压缩包中运行。

需要Windows 10/11、系统Windows PowerShell 5.1与.NET Framework 4.8。官方WuwaTappo需自行安装、登录，当前适配1.0.2 / 1.0.3；无需另装Python或Node.js。

2 · 完成首次使用向导

  1. 双击助手，处理正常UAC确认，在向导里点“选择程序…”选中官方WuwaTappo.exe，点击校验。
  2. 手动启动官方桌宠并登录，等连接成功后继续；也可以选择“稍后连接”。
  3. 点击“保存并进入主界面”。路径自动保存，无需手动改JSON。取消或按Esc不会覆盖原配置。

向导不自动发键或领取。正常保存后下次跳过；需重设时退出助手，在助手目录运行 .\WuwaTappoHelper.exe --setup。

高级：手动配置路径

方法A：把整个助手文件夹放在官方安装目录内，让官方EXE位于助手目录的上一级：

官方桌宠目录/
├── WuwaTappo.exe
└── WuwaTappoHelper/
    ├── WuwaTappoHelper.exe
    └── 其余助手文件……

方法B：助手放在其他地方时，复制 helper-config.example.json，重命名副本为 helper-config.json，用记事本编辑，换成自己的真实路径：

{
  "OfficialExecutable": "D:/Games/WuwaTappo/WuwaTappo.exe"
}

使用正斜杠最省事。开启资源管理器“文件扩展名”，确认不是helper-config.json.txt。应选择官方桌宠EXE，不是助手、卸载程序或快捷方式。修改后重启助手。

3 · 先连接，暂不开自动任务

  1. 启动官方桌宠并登录，确认桌宠出现。
  2. 双击助手EXE，核对文件来源，处理正常UAC确认。
  3. 等待连接，核对余额和左右槽位。默认两个自动任务均关闭。

启动失败先检查是否完整解压、配置路径是否正确，以及diagnostics/uia-host.log与uia-startup.log。遇到签名或安全提示时先核对来源，不建议关闭安全防护。

4 · 验证，再开始

  1. 需要自动补充时，保持助手前台，点击“验证 F24 · 5次”，停止键鼠操作约12秒，等待通过。
  2. “验证领取 · 单箱”是可选测试，会真实消耗约1,000余额并领取一个箱子。
  3. 按需选择自动补充与自动领取，点击“开始运行”。只用自动领取不要求F24验证。

每次重开助手或官方窗口身份变化后需重做F24验证。目标储备为2,000，箱子就绪优先处理；助手不加速官方冷却。

5 · 暂停、托盘与退出

  • Ctrl+Alt+F8 开始/暂停；Ctrl+Alt+F9 停止自动动作。
  • 输入框保持焦点时会持续避让；点击框外恢复。鼠标移动、滚轮不延长等待，近期键盘输入后约1秒再尝试。
  • 窗口“×”和最小化仅隐藏到托盘。双击托盘图标恢复，右键“退出程序”才真正退出。
  • 升级前退出旧助手，完整解压新版，按需复制路径配置，再重新验证。

遇到问题

持续等待连接：检查官方桌宠是否已运行登录、路径、权限和版本。一直避让：点输入框外，查看状态原因。补充停住：可能已到储备目标、正在等领取或冷却。请勿同时开启多个类似助手。

日志保存在本机，可能包含路径、余额、窗口标识，分享前请脱敏。请勿上传官方账号或整个安装目录。
